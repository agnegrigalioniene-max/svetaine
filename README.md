# Millennial Medical crutches for the EU (concept)

Concept page for EU distribution of Millennial Medical crutches.
Not affiliated with or endorsed by Millennial Medical. Product names, descriptions and photos are from crutches.com.

Plain HTML, CSS and JavaScript, no build step. Deployed on Vercel from this repository.

Local preview: `node serve.mjs`, then open http://localhost:8765/
